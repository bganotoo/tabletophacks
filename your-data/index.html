Privacy

Everything you save on Tabletop Hacks lives in this browser, on this device. None of it is sent anywhere — which also means nobody else can get it back for you. A backup file is the only copy that survives clearing your browsing data.

Saved in this browser

Back up and restore

A backup is one JSON file covering every tool on the site — packs, saved results, encounters, score sheets, timers, and settings. Restoring it replaces only what the file contains and leaves everything else alone.

Good to know

  • Moving to another device: back up here, open this page on the other device, and restore the file.
  • Private or incognito windows forget everything when they close. Back up before you close one.
  • Just one tool? The Initiative Tracker, Score Tracker, and Game Timer each have their own Export button, the Generator exports its library, and the Workshop exports single packs.
